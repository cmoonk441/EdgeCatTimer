가장자리 고양이 타이머 0.1

Windows 10/11 Intel·AMD 64비트 PC용 첫 시험 버전입니다.

1. 압축을 풀고 EdgeCatTimer.exe를 실행하세요.
2. 처음에는 [10초 시험] → [시작]으로 확인하세요.
3. 시계 옆 고양이 아이콘을 누르면 설정 창이 다시 열립니다.
   아이콘이 안 보이면 숨겨진 아이콘(∧)을 확인하세요.
4. 원하는 시간과 모니터를 선택하고 사용하세요.

Ctrl+Alt+P : 일시정지 / 재개
Ctrl+Alt+S : 중단 / 초기화
완전히 종료 : 설정 창 또는 시계 옆 아이콘 메뉴에서 [종료]

설정 창의 X는 창만 숨깁니다. 타이머는 계속 실행됩니다.
PNG·JPG는 이미지가 이동하며, GIF는 원래 애니메이션을 재생합니다.
Windows 실행 파일 빌드와 계산 테스트는 통과했지만,
실제 Windows의 화면 표시·듀얼 모니터·메모리 사용량은 미검증입니다.
