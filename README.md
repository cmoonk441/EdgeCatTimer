# 가장자리 고양이 타이머 0.1

Windows 10(버전 1607 이상) / Windows 11의 **Intel·AMD 64비트 PC용 첫 시험 버전**입니다.
설정한 시간 동안 고양이가 선택한 모니터를 한 바퀴 돌고 출발점에서 멈춥니다.

## 바로 사용하기

1. ZIP 파일의 압축을 풉니다.
2. **EdgeCatTimer.exe**를 실행합니다. 설치나 관리자 권한은 필요하지 않습니다.
3. 처음에는 **10초 시험 → 시작**으로 이동을 확인해 보세요.
4. 시계 옆 알림 영역의 고양이 아이콘을 누르면 설정 창이 다시 열립니다. 아이콘이 안 보이면 숨겨진 아이콘 표시(∧)를 확인하세요.
5. 원하는 시간과 모니터를 선택하고 시작합니다.

Python, .NET, Visual Studio는 사용에 필요하지 않습니다. 아래 소스 빌드 안내는 직접 코드를 수정할 때만 필요합니다.

## 동작과 설정

| 항목 | 동작 |
| --- | --- |
| 시간 | 1초~999시간 59분 59초. 시간·분·초를 직접 입력합니다. |
| 이동 방향 | 왼쪽 위 출발 → 왼쪽 아래 → 오른쪽 아래 → 오른쪽 위 → 왼쪽 위. |
| 이동 속도 | 전체 경로를 같은 속도로 이동합니다. 긴 변에서는 더 오래 걷습니다. |
| 캐릭터 회전 | 기본으로 각 변에서 90도씩 회전해 발이 가장자리를 향합니다. 모서리에서는 즉시 방향이 바뀝니다. |
| 한 바퀴 완료 | 출발점에서 이동과 애니메이션이 멈춥니다. 알림 소리를 끌 수 있습니다. |
| 일시정지 / 재개 | 남은 시간, 현재 위치, 애니메이션을 보존합니다. 정지해 있던 시간은 제외합니다. |
| 중단 / 초기화 | 현재 타이머를 취소하고 고양이를 숨깁니다. 다음 시작은 출발점부터입니다. |
| 모니터 | 자동 감지된 모니터 한 대를 선택합니다. 해상도를 직접 입력할 필요가 없습니다. |
| 작업표시줄 | 포함/제외를 선택할 수 있습니다. 기본값은 포함입니다. |
| 크기 / 여백 | 캐릭터 48~160px, 안쪽 여백 0~99px. 크기는 화면의 실제 픽셀 기준입니다. |
| 기본 고양이 | 프로그램에 들어 있는 4프레임 도트 고양이입니다. 외부 파일이 없어도 됩니다. |
| PNG / JPG / BMP | 정지 이미지를 이동시킵니다. 사진 자체에 걷는 동작을 만들지는 않습니다. |
| GIF | 원래 GIF의 애니메이션을 재생하며 이동합니다. |
| 좌우 반전 | 왼쪽을 바라보는 사용자 이미지를 오른쪽 방향으로 맞출 때 사용합니다. |
| 설정 창의 X | 설정 창을 숨깁니다. 타이머는 계속 작동합니다. 완전히 닫으려면 '종료'를 선택합니다. |

캐릭터를 포함한 투명 창은 마우스 클릭을 통과시킵니다. 뒤에 있는 브라우저, PDF, VS Code 등을 계속 사용할 수 있습니다. 파란 배경이나 테두리 선을 실제 화면에 그리지는 않습니다.

**단축키**: Ctrl+Alt+P = 일시정지·재개, Ctrl+Alt+S = 중단. 다른 프로그램과 충돌하면 알림이 나오며, 설정 창이나 트레이 메뉴를 사용하면 됩니다.

**잠자기/최대 절전**: PC가 잠든 시간은 계산하지 않습니다. 깨어나면 남은 시간부터 계속합니다. 화면 잠금은 타이머를 멈추지 않습니다. 앱 종료 후 실행 중이던 타이머를 복구하는 기능은 아직 없습니다.

## 사용자 이미지 안내

- 오른쪽을 바라보고 아래쪽에 발이 있는 투명 PNG/GIF가 가장 자연스럽습니다.
- 모든 프레임에 공통인 바깥 투명 여백을 줄이고, 이미지의 아래쪽을 발 위치로 사용합니다. 사진의 실제 발 위치를 자동 인식하는 기능은 아닙니다.
- JPG처럼 배경이 있는 사진은 사각형 배경도 함께 보입니다. 자동 배경 제거 기능은 없습니다.
- 이미지 원본은 그대로 둡니다. 설정에는 파일 경로가 저장되므로 원본을 옮기면 기본 고양이로 돌아갑니다.
- 큰 GIF가 메모리를 과하게 쓰지 않도록 20MB, 가로·세로 각각 2048px, 최대 200프레임으로 제한합니다. 프레임 전체 원본 픽셀 합계는 16,777,216, 표시 프레임 캐시는 32MB까지입니다.
- GIF의 매우 짧은 프레임 간격은 50ms 이상으로 처리합니다. APNG, 애니메이션 WebP, 동영상은 지원하지 않습니다.

## 가볍게 만든 방식

- C++와 Windows 기본 기능(Win32, GDI+)만 사용합니다.
- 화면 전체가 아니라 고양이 크기의 작은 투명 창 하나를 그립니다.
- 실행 중에는 50ms 간격으로 위치를 확인하고, 기본 걷기 프레임은 초당 8장입니다.
- 위치와 그림이 모두 같으면 다시 그리지 않습니다. 정지·완료·대기 중에는 반복 타이머를 끕니다.
- 시간이 흐른 횟수를 세는 대신 Windows의 단조 시간으로 진행률을 계산해, 표시가 늦어진 만큼 타이머가 계속 늘어나는 것을 방지합니다.
- 인터넷 통신, 광고, 자동 업데이트, 화면 캡처, 시작 프로그램 등록은 포함하지 않았습니다.
- 설정만 `%LOCALAPPDATA%\EdgeCatTimer\settings.ini`에 저장합니다.

**실행 파일 크기는 실행 중 메모리 사용량과 다릅니다.** 실제 RAM·CPU 수치는 Windows 작업 관리자에서 측정해야 하며, 사용자 GIF에 따라 달라집니다. 이 버전에는 측정하지 않은 성능 수치를 표시하지 않습니다.

## 아직 확인이 필요한 환경

이 파일은 Linux에서 Windows용으로 빌드했습니다. 계산 검증과 호환 환경의 실행 확인 결과는 VALIDATION.md에 기록합니다. 실제 Windows PC의 듀얼 모니터, 배율 혼합(100%/150% 등), 작업표시줄 위치, 절전 복귀는 확인이 필요합니다.

일반 프로그램 위에 표시하도록 만들었습니다. 독점 전체화면 게임, 보안 데스크톱(UAC), 일부 다른 최상위 창에서는 보이지 않을 수 있습니다. 모니터 연결이 바뀌면 다시 감지하며, 선택한 모니터가 사라지면 주 모니터로 이동합니다.

디지털 서명은 적용하지 않은 시험 버전입니다. Windows의 실행 경고가 나타날 수 있습니다. 외부 배포 전에는 실제 Windows 검증과 코드 서명·설치 패키지 작업을 진행하는 것이 다음 단계입니다.

## 제작·배포 과정

1. **기능 정리**: 시간, 모니터, 캐릭터, 정지 동작을 정합니다.
2. **첫 실행 파일 제작**: 작은 투명 창, 경로 계산, GIF 표시, 설정 창을 연결합니다. 이 패키지가 해당 단계의 결과입니다.
3. **내 PC에서 시험**: 먼저 10초, 다음 25분으로 실행하고 정지·재개·듀얼 모니터·해상도 변경을 확인합니다. 작업 관리자에서 RAM과 CPU도 측정합니다.
4. **사용감 수정**: 고양이 크기, 디자인, 모서리 동작, 알림 방식을 원하는 대로 바꿉니다.
5. **배포**: 개인 사용은 ZIP 안의 EXE로 충분합니다. 여러 사람에게 제공하려면 버전 관리, 실제 Windows 테스트, 코드 서명, 필요하면 MSIX 등 설치 패키지를 추가합니다.

## 소스 구성

```text
EdgeCatTimer.exe       실행 파일
src/main.cpp          설정 창, 트레이, 모니터, 투명 창, 이미지 처리
src/core.hpp          타이머 상태와 사각 경로 계산
src/cat.hpp           기본 도트 고양이 픽셀과 걷기 프레임
src/app.manifest      DPI/실행 권한 설정
src/app.rc            아이콘과 버전 리소스
assets/cat.ico        프로그램 아이콘
tests/core_test.cpp   시간·좌표 계산 검증
build_windows.cmd    Windows용 소스 빌드
build_zig.sh         Zig를 이용한 교차 빌드
```

Windows에서 수정 후 빌드하려면 Visual Studio Build Tools의 **C++를 사용한 데스크톱 개발**을 설치한 뒤, **x64 Native Tools Command Prompt for VS**에서 `build_windows.cmd`를 실행합니다. 코드는 UTF-8입니다.

첨부 실행 파일은 Zig 0.13.0의 C++ 컴파일러로 만들었습니다. Linux에서 같은 버전으로 `bash build_zig.sh`를 실행할 수 있습니다. 핵심 계산 테스트는 `g++ -std=c++17 tests/core_test.cpp -o core_test`로 빌드하고 실행합니다.
